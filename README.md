# NEW!  FT-CONTEST-HELPER for FT4 and FT8

The FT-Contest Helper was developed to make contest operation with FT4 and FT8 easier and more efficient. It handles time-critical tasks to ensure smooth contest operation and helps identify new multipliers to achieve the best possible contest results.

Unlike the FT8 Helper, the FT-Contest Helper cannot operate as an “FT8 robot.” The operator must manually approve each QSO to ensure compliance with the requirements for legal contest operation.

Some of the key features are:
- Finds and initiates the next QSO with the best chances of success and the highest potential score.
- Stops calling after the configured maximum number of attempts.
- Prioritizes stations by multiplier or distance, depending on the contest type.
- Supports all contests available in WSJT-X.
- Regular QSOs are also supported for testing the FT-Contest Helper.
- Supports S&P, RUN (CQ), and mixed S&P/CQ operation.
- It continuously searches for new multipliers in the background and automatically prioritizes them to maximize the contest score.
- Both CQ-calling stations and stations sending 73/RR73 are taken into account.
- Stations with more than two unsuccessful QSO attempts are temporarily blocked for a configurable period.
- The FT-Contest Helper was developed as a macro extension using Quick Macros (© Gintaras Didzgalvis).
- No Quick Macros license is required to run the program.
- Easy to install and use as portable software.
